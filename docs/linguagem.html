A Sophia

Sophia é uma linguagem de programação educacional escrita com uma sintaxe em português.

Seu objetivo é permitir que estudantes desenvolvam o pensamento lógico e algorítmico utilizando uma linguagem simples e expressiva.

Uma linguagem, não apenas uma sintaxe

Sophia possui um analisador léxico, analisador sintático, árvore sintática abstrata e interpretador próprio.

Isso significa que os programas escritos em Sophia são realmente analisados e executados pela própria linguagem.

Por que português?

A escolha do português procura reduzir uma barreira inicial para estudantes que estão tendo seu primeiro contato com programação.

O objetivo não é esconder os conceitos fundamentais da programação, mas permitir que eles sejam aprendidos antes que a complexidade da sintaxe de uma linguagem profissional se torne relevante.

O que Sophia não pretende ser

Sophia não pretende substituir Java, Python, C#, JavaScript ou outras linguagens utilizadas profissionalmente.

Seu propósito é educacional.

Sophia procura ser uma ponte entre o aprendizado da lógica de programação e o desenvolvimento profissional de software.
