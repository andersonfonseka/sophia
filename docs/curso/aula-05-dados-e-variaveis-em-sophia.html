Aula 05 — Dados e variáveis em Sophia

Objetivos

Ao final desta aula, você será capaz de compreender o que são dados e variáveis, identificar tipos de dados, atribuir valores e acompanhar mudanças durante a execução.

Provocação

Um algoritmo precisa trabalhar com informações. Se queremos calcular a idade de uma pessoa, o preço de uma compra ou uma nota, precisamos guardar esses dados durante a execução.

Essas informações são representadas por variáveis.

1. O que é um dado?

Um dado é uma informação utilizada pelo algoritmo.

Exemplos:

  • 25
  • "Sophia"
  • 8.5
  • VERDADEIRO

Um algoritmo recebe, transforma e produz dados.

2. O que é uma variável?

Uma variável é um nome utilizado para representar um valor.

Por exemplo, idade pode representar a idade de uma pessoa.

O valor associado a uma variável pode mudar durante a execução.

3. Tipos de dados

| Tipo | Representa | Exemplo | |---|---|---| | NUMERO | números | 25 | | TEXTO | textos | "Sophia" | | LOGICO | verdadeiro ou falso | VERDADEIRO | | DATA | datas | 09/09/2026 | | HORA | horários | 19:30 | | LISTA | coleção de valores | lista de notas |

4. Declarando dados

PROGRAMA "Dados"

INICIO
    NUMERO idade RECEBE 12
    TEXTO nome RECEBE "Sophia"
    LOGICO aprovado RECEBE VERDADEIRO

    ESCREVA idade
    ESCREVA nome
    ESCREVA aprovado
FIM

Cada variável possui um nome e um tipo.

5. Atribuição

RECEBE atribui um valor a uma variável.

idade RECEBE 12
idade RECEBE 13

Ao final, idade representa 13.

6. Rastreando a execução

PROGRAMA "Dados"

INICIO
    NUMERO pontos RECEBE 10
    pontos RECEBE 20
    pontos RECEBE 35
    ESCREVA pontos
FIM

| Momento | Valor | |---|---:| | primeira atribuição | 10 | | segunda atribuição | 20 | | terceira atribuição | 35 |

A saída será 35.

Exercícios

Nível A — Compreender

  1. O que é um dado?
  2. O que é uma variável?
  3. Para que serve o tipo de dado?
  4. Qual tipo representa texto?
  5. Qual tipo representa verdadeiro ou falso?

Nível B — Traduzir

Crie nomes de variáveis para: idade, nome, nota e situação de aprovação.

Nível C — Construir

Crie um programa que armazene nome, idade e nota de um aluno e apresente os três dados.

Nível D — Rastrear

Determine os valores finais de a e b:

INICIO
    NUMERO a RECEBE 10
    NUMERO b RECEBE 20
    a RECEBE 30
    b RECEBE 40
FIM

Nível E — Corrigir

Explique o problema:

    NUMERO nome
    TEXTO idade

Desafio

Crie um cadastro de aluno usando pelo menos três variáveis de tipos diferentes.

Síntese

Dados representam informações. Variáveis dão nomes a essas informações. Tipos indicam que espécie de dado está sendo representada. RECEBE atribui valores, e uma variável pode mudar durante a execução.
