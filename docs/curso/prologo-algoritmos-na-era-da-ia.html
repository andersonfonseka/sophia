Curso de Algoritmos I

Prólogo — Algoritmos na era da IA

Por que se interessar em aprender algoritmos na era da IA?

Hoje, uma inteligência artificial consegue escrever programas em poucos segundos.

Ela pode sugerir código, criar funções, explicar erros e até montar uma solução completa a partir de uma descrição.

Então surge uma pergunta importante:

Se a IA já consegue programar, por que aprender algoritmos?

Porque programar não é apenas escrever código.

Antes de existir um programa, existe um problema.

E antes de existir código, alguém precisa compreender esse problema, decidir o que deve ser feito, organizar uma solução e verificar se ela realmente funciona.

É aí que entra o pensamento algorítmico.

O papel do ser humano

A IA pode ajudar a escrever o programa.

Mas alguém ainda precisa:

  • compreender o problema;
  • identificar o objetivo;
  • separar o problema em partes;
  • definir os dados necessários;
  • organizar uma solução;
  • avaliar as alternativas;
  • testar os resultados;
  • identificar erros;
  • validar se a solução realmente resolve o problema.

Por isso, aprender algoritmos continua sendo importante.

A tecnologia muda.

A capacidade de pensar sobre problemas continua sendo necessária.

Algoritmo não é código

Um algoritmo é uma solução organizada em passos.

O código é uma forma de expressar essa solução para que um computador possa executá-la.

Podemos pensar na seguinte sequência:

PROBLEMA → COMPREENSÃO → DECOMPOSIÇÃO → SOLUÇÃO → ALGORITMO → SOPHIA → EXECUÇÃO → TESTE → VALIDAÇÃO

O código aparece depois que a solução já foi pensada.

Por que começar pelo problema?

Imagine que alguém peça:

Faça um programa para calcular o valor de uma compra.

Antes de escrever qualquer código, precisamos perguntar:

  • Qual é o valor da compra?
  • Existe desconto?
  • Como o desconto é calculado?
  • Qual resultado deve ser apresentado?
  • Quais dados precisam ser informados?

Sem compreender essas questões, podemos produzir um programa que executa perfeitamente e, ainda assim, resolve o problema errado.

Pensamento algorítmico

Pensar algoritmicamente significa organizar o raciocínio para transformar um problema em uma sequência de passos que possa ser executada.

Isso envolve:

  1. compreender;
  2. decompor;
  3. organizar;
  4. expressar;
  5. testar;
  6. validar.

O objetivo deste curso não é apenas ensinar uma linguagem.

É desenvolver essa forma de pensar.

O papel da Sophia

Sophia será a linguagem usada para expressar os algoritmos construídos durante o curso.

A linguagem foi projetada para que o código seja expressivo e compreensível.

Por isso, o curso não começa ensinando uma grande quantidade de comandos.

Primeiro aprendemos a pensar.

Depois aprendemos a expressar esse pensamento.

E onde entra a IA?

A inteligência artificial pode ser uma ferramenta poderosa durante o aprendizado.

Ela pode:

  • sugerir soluções;
  • explicar conceitos;
  • gerar exemplos;
  • encontrar possíveis erros;
  • propor testes;
  • comparar estratégias.

Mas a IA não substitui a necessidade de compreender o problema e validar a solução.

Uma resposta gerada por IA não é automaticamente uma solução correta.

O que você aprenderá

Ao longo do curso, você aprenderá a:

  • compreender problemas;
  • transformar problemas em algoritmos;
  • trabalhar com dados;
  • construir expressões;
  • tomar decisões;
  • repetir operações;
  • criar funções;
  • trabalhar com listas;
  • modelar dados;
  • testar algoritmos;
  • depurar soluções;
  • utilizar IA de forma consciente durante a programação.

A ideia central

Você não termina este curso apenas sabendo programar em Sophia.

Você termina o curso sabendo pensar algoritmicamente.

Esse é o objetivo.

Síntese

A IA pode escrever código.

Mas alguém precisa saber o que deve ser construído, por que deve ser construído e como verificar se está correto.

Aprender algoritmos é desenvolver essa capacidade.
