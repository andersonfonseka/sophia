Curso de Algoritmos I

Aula 03 — Expressando algoritmos com Sophia

Do algoritmo para a linguagem

Nas aulas anteriores, aprendemos a pensar em soluções antes de escrever código.

Agora vamos dar o próximo passo:

expressar o algoritmo em Sophia.

Sophia foi criada para tornar essa expressão clara e próxima da forma como pensamos a solução.

A estrutura básica

Um programa Sophia possui uma estrutura que delimita o programa e seu início e fim.

PROGRAMA "Saudacao"
INICIO
    ESCREVA "Olá"
FIM

Podemos ler esse programa de forma direta:

  • PROGRAMA identifica o programa;
  • INICIO indica o começo da execução;
  • ESCREVA apresenta uma informação;
  • FIM encerra o programa.

O código deve expressar a solução

Considere o algoritmo:

  1. iniciar;
  2. apresentar uma mensagem;
  3. terminar.

Em Sophia:

PROGRAMA "Saudacao"
INICIO
    ESCREVA "Olá"
FIM

A estrutura do código acompanha a estrutura do algoritmo.

Escrevendo informações

O comando ESCREVA apresenta uma informação.

Exemplo:

PROGRAMA "Mensagem"
INICIO
    ESCREVA "Bem-vindo ao curso de Algoritmos I"
FIM

A intenção do programa fica explícita.

Lendo dados

Quando precisamos receber uma informação, usamos LEIA.

Exemplo:

PROGRAMA "Nome"
INICIO
    TEXTO nome RECEBE ""
    LEIA "Escreva seu nome " nome
    ESCREVA nome
FIM

O programa:

  1. declara uma variavel chamada nome;
  2. informa que ele é do tipo TEXTO;
  3. toda a variavel deve ser iniciado com um valor, nesse caso, nome RECEBE "";
  4. lê o valor, toda leitura segue o formato LEIA [TEXTO INFORMATIVO] nome_da_variavel;
  5. apresenta o valor.

Dados fazem parte do problema

Antes de escrever o programa, precisamos identificar quais informações o problema utiliza.

Se queremos calcular o dobro de um número, precisamos de um número.

Podemos expressar isso em Sophia:

PROGRAMA "Dobro"
INICIO
    NUMERO num recebe 0
    LEIA "Digite um numero " num
    ESCREVA num VEZES 2
FIM

Observe que o programa segue o algoritmo:

  1. receber um número;
  2. multiplicar por 2;
  3. apresentar o resultado.

Código expressivo

O código deve permitir que outra pessoa compreenda a solução.

Compare:

PROGRAMA "Dobro"
INICIO
    NUMERO num recebe 0
    LEIA "Digite um numero " num
    ESCREVA num VEZES 2
FIM

com uma solução que escondesse a intenção em uma sequência difícil de interpretar.

A primeira solução é mais clara porque os nomes e as estruturas ajudam a revelar o que está acontecendo.

A linguagem não substitui o algoritmo

Aprender os comandos de Sophia não elimina a necessidade de pensar.

Se o problema não foi compreendido, conhecer a sintaxe não resolve a situação.

A sequência continua sendo:

PROBLEMA → ALGORITMO → SOPHIA

Sophia é a forma de expressar a solução.

Um primeiro programa completo

Problema:

Receber um número e apresentar seu dobro.

Algoritmo:

  1. receber um número;
  2. multiplicar o número por 2;
  3. apresentar o resultado.

Sophia:

PROGRAMA "Dobro"
INICIO
    NUMERO num recebe 0
    LEIA "Digite um numero " num
    ESCREVA num VEZES 2
FIM

Testando

Se o usuário fornecer:

7

o programa deverá produzir:

14

Agora podemos comparar:

Problema: calcular o dobro.

Algoritmo: receber → multiplicar → apresentar.

Programa: expressa esses passos em Sophia.

Atividade 1 — Leia o programa

Observe:

PROGRAMA "Soma"

INICIO
    NUMERO primeiro RECEBE 0
    NUMERO segundo RECEBE 0
    LEIA "Digite o primeiro valor " primeiro
    LEIA "Digite o segundo valor " segundo
    ESCREVA primeiro MAIS segundo
FIM

Responda:

  1. quais as variáveis foram criadas?
  2. qual é o tipo dessas variveis?
  3. quais valores são lidos?
  4. qual resultado é apresentado?

Atividade 2 — Traduza um algoritmo

Transforme o algoritmo abaixo em Sophia:

  1. receber um número;
  2. multiplicar por 3;
  3. apresentar o resultado.

Atividade 3 — Teste mentalmente

Considere o programa do dobro.

Execute-o para:

  • 2;
  • 5;

Registre os resultados.

Desafio

Crie um programa Sophia que receba duas notas e apresente a soma das duas notas.

Antes de escrever o código:

  1. identifique as entradas;
  2. descreva o processamento;
  3. defina a saída;
  4. escreva o programa.

Síntese

Nesta aula aprendemos que:

  • Sophia expressa algoritmos;
  • PROGRAMA, INICIO e FIM estruturam o programa;
  • DADOS declara os dados utilizados;
  • LEIA recebe informações;
  • ESCREVA apresenta informações;
  • o algoritmo continua sendo a base da solução.
