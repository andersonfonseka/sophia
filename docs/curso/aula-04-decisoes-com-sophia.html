Curso de Algoritmos I

Aula 04 — Tomando decisões com Sophia

Algoritmos precisam tomar decisões

Até agora, trabalhamos com algoritmos que seguem uma sequência de passos.

Mas muitos problemas não possuem apenas um caminho.

Dependendo dos dados recebidos, o algoritmo pode precisar fazer uma coisa ou outra.

Por exemplo:

Se a nota for suficiente, apresentar que o aluno foi aprovado. Caso contrário, apresentar que ele não foi aprovado.

Agora existe uma decisão.

A ideia da condição

Uma condição é uma afirmação que pode ser avaliada como verdadeira ou falsa.

Por exemplo:

A nota é maior ou igual a 6?

A resposta pode ser:

  • sim;
  • não.

Em um algoritmo, essa resposta pode determinar qual caminho será executado.

Decisão com SE

Em Sophia, usamos SE para representar uma decisão.

Exemplo:

PROGRAMA "Aprovacao"

INICIO
    NUMERO nota recebe 0
    LEIA "Digite uma nota " nota

    SE nota MAIOR OU IGUAL A 6
        ESCREVA "Aprovado"
    FIM
FIM

Podemos ler:

Se a nota for maior ou igual a 6, escreva "Aprovado".

Decisão com SENAO

Quando existem dois caminhos, podemos usar SENAO.

PROGRAMA "Aprovacao"

INICIO
    NUMERO nota recebe 0
    LEIA "Digite uma nota " nota

    SE nota MAIOR OU IGUAL A 6
        ESCREVA "Aprovado"
    SENAO
        ESCREVA "Reprovado"
    FIM
FIM

Agora o algoritmo possui dois caminhos.

Se a condição for verdadeira:

Aprovado

Se a condição for falsa:

Reprovado

A condição vem do problema

Não devemos começar pensando:

Qual comando vou usar?

Devemos começar pensando:

Qual decisão o problema exige?

No problema da aprovação, a decisão é:

A nota é maior ou igual a 6?

Depois transformamos essa decisão em uma condição de Sophia.

Comparações

As condições podem utilizar comparações.

Algumas comparações disponíveis em Sophia são:

  • IGUAL A;
  • DIFERENTE DE;
  • MAIOR QUE;
  • MAIOR OU IGUAL A;
  • MENOR QUE;
  • MENOR OU IGUAL A.

Exemplo:

SE idade MAIOR OU IGUAL A 18
    ESCREVA "Maior de idade"
FIM

Outro exemplo

Problema:

Verificar se um número é positivo.

Algoritmo:

  1. receber um número;
  2. verificar se ele é maior que zero;
  3. se for, informar que é positivo.

Sophia:

PROGRAMA "Positivo"
INICIO
    NUMERO num recebe 0
    LEIA "Digite um numero " num

    SE num MAIOR QUE 0
        ESCREVA "Positivo"
    FIM
FIM

Com dois caminhos

Podemos informar também quando o número não é positivo.

PROGRAMA "PositivoOuNao"
INICIO
    NUMERO num recebe 0
    LEIA "Digite um numero " num

    SE num MAIOR QUE 0
        ESCREVA "Positivo"
    SENAO
        ESCREVA "Nao Positivo"
    FIM
FIM

Observe que a decisão possui exatamente dois caminhos.

Decisões encadeadas

Alguns problemas possuem mais de duas possibilidades.

Por exemplo:

  • nota maior ou igual a 7: aprovado;
  • nota maior ou igual a 5: recuperação;
  • nota menor que 5: reprovado.

Uma solução pode utilizar decisões em sequência:

PROGRAMA "Resultado"
INICIO
    NUMERO nota RECEBE 0
    LEIA "Digite uma nota " nota

    SE nota MAIOR OU IGUAL A 7
        ESCREVA "Aprovado"
    SENAO
        SE nota MAIOR OU IGUAL A 5
            ESCREVA "Recuperacao"
        SENAO
            ESCREVA "Reprovado"
        FIM
    FIM
FIM

A segunda decisão só é necessária quando a primeira condição não foi atendida.

Pensando antes de escrever

Antes de construir uma decisão, responda:

  1. Qual é a pergunta?
  2. Quais respostas são possíveis?
  3. O que acontece quando a condição é verdadeira?
  4. O que acontece quando ela é falsa?

Esse raciocínio ajuda a evitar decisões incompletas.

Testando uma decisão

Considere o programa de aprovação.

Teste com:

8

A condição:

nota MAIOR OU IGUAL A 6

é verdadeira.

Resultado:

Aprovado

Agora teste com:

4

A condição é falsa.

Resultado:

Reprovado

Testando o limite

Também devemos testar valores próximos do limite.

Para uma aprovação com nota maior ou igual a 6, teste:

  • 5;
  • 5.9;
  • 6;
  • 6.1;

O valor 6 é especialmente importante porque representa o limite da condição.

Atividade 1 — Identifique a decisão

Qual é a condição necessária para resolver cada problema?

  1. verificar se uma pessoa pode entrar em um evento para maiores de idade;
  2. verificar se um número é maior que 100;
  3. verificar se uma nota permite aprovação.

Atividade 2 — Complete o algoritmo

Problema:

Receber um número e informar se ele é maior que zero.

Escreva os passos antes de escrever o programa.

Atividade 3 — Teste

Para o programa de aprovação, determine o resultado para:

  • 4;
  • 5;
  • 6;
  • 7;

Desafio

Crie um programa Sophia que receba a idade de uma pessoa e apresente:

  • Maior de idade quando a idade for maior ou igual a 18;
  • Menor de idade nos demais casos.

Antes do código, escreva o algoritmo.

Síntese

Nesta aula aprendemos que:

  • problemas podem exigir decisões;
  • condições podem ser verdadeiras ou falsas;
  • SE representa uma decisão;
  • SENAO representa o caminho alternativo;
  • comparações permitem construir condições;
  • testes devem incluir valores comuns e valores de limite.

Agora já conseguimos construir algoritmos que não apenas executam uma sequência, mas também escolhem caminhos de acordo com os dados.

A próxima etapa será aprender a trabalhar com diferentes tipos de dados e valores.
