Curso de Algoritmos I

Aula 01 — O que é um algoritmo?

Antes de aprender a programar, precisamos aprender a organizar uma solução.

Retomando o prólogo

No prólogo, vimos que a inteligência artificial pode ajudar a escrever código.

Mas o código é apenas uma parte da solução.

Primeiro precisamos compreender o problema e organizar aquilo que queremos fazer.

Essa organização pode ser expressa por meio de um algoritmo.

O que é um algoritmo?

Um algoritmo é uma sequência de instruções organizadas logicamente para realizar uma tarefa ou resolver um problema.

A ideia principal está em três pontos:

  • existe um objetivo;
  • existem passos;
  • os passos precisam estar organizados.

Um algoritmo transforma uma intenção em uma sequência que pode ser seguida.

Um exemplo do cotidiano

Imagine que você queira preparar um copo de água com gelo.

Uma sequência possível é:

  1. pegar um copo;
  2. colocar gelo no copo;
  3. colocar água no copo;
  4. servir.

Existe uma ordem.

Não faria sentido colocar a água depois de entregar o copo.

A ordem dos passos faz parte da solução.

Um algoritmo precisa ser executável

Os passos precisam ser suficientemente claros para que possam ser realizados.

Compare:

Faça um café.

com:

Coloque água no recipiente, aqueça a água, coloque o café e misture.

A segunda descrição apresenta uma sequência mais organizada.

Quanto mais importante for a precisão da tarefa, maior será a necessidade de deixar os passos claros.

Algoritmo e programa

Algoritmo e programa não são a mesma coisa.

O algoritmo representa a solução organizada.

O programa é a implementação dessa solução em uma linguagem de programação.

Podemos pensar assim:

Problema → Algoritmo → Programa

O algoritmo vem antes do programa.

Entrada, processamento e saída

Muitos problemas podem ser entendidos a partir de três elementos:

Entrada → Processamento → Saída

Por exemplo, queremos calcular o dobro de um número.

Entrada

Um número é fornecido.

Processamento

O número é multiplicado por 2.

Saída

O resultado é apresentado.

A solução pode ser descrita assim:

  1. receber um número;
  2. calcular o dobro;
  3. apresentar o resultado.

Esse é um algoritmo.

A ordem dos passos importa

Considere:

  1. apresentar o resultado;
  2. receber o número;
  3. calcular o dobro.

Essa sequência não resolve corretamente o problema.

O algoritmo precisa respeitar as dependências entre os passos.

Primeiro precisamos obter o dado.

Depois podemos processá-lo.

Finalmente podemos apresentar o resultado.

Algoritmos precisam ter um objetivo

Um conjunto de passos só faz sentido quando está relacionado a uma tarefa ou problema.

Por isso, ao construir um algoritmo, pergunte:

O que eu quero resolver?

Essa pergunta ajuda a evitar passos desnecessários.

Um algoritmo pode ser simples

Um algoritmo não precisa ser complicado para ser importante.

Resolver um problema simples ajuda a desenvolver uma habilidade fundamental:

transformar uma ideia em passos organizados.

Essa habilidade será usada em problemas cada vez maiores.

Testando mentalmente um algoritmo

Antes de programar, podemos executar o algoritmo mentalmente.

Considere:

  1. receber o número 7;
  2. calcular o dobro;
  3. apresentar o resultado.

Executando os passos:

  • entrada: 7;
  • processamento: 7 vezes 2;
  • saída: 14.

O algoritmo produziu o resultado esperado.

Decomposição

Problemas maiores podem ser divididos em problemas menores.

Por exemplo, preparar uma viagem envolve várias tarefas:

  • escolher o destino;
  • definir a data;
  • escolher o transporte;
  • reservar hospedagem;
  • organizar a bagagem.

Cada parte pode ser pensada separadamente.

Essa capacidade de dividir um problema será muito importante durante o curso.

Algoritmo antes da linguagem

Um algoritmo não depende de uma linguagem específica.

Podemos descrever a mesma solução de diferentes maneiras.

A linguagem de programação será usada para expressar essa solução de forma que o computador possa executá-la.

No curso, usaremos Sophia para fazer essa expressão.

Atividades

Atividade 1 — Identifique o objetivo

Escolha uma tarefa simples do cotidiano e responda:

Qual é o objetivo?

Atividade 2 — Organize os passos

Descreva uma sequência de passos para realizar a tarefa escolhida.

Atividade 3 — Procure problemas

Leia sua sequência e pergunte:

  • algum passo está fora de ordem?
  • existe algum passo desnecessário?
  • falta alguma informação?
  • outra pessoa conseguiria executar os passos?

Atividade 4 — Teste

Escolha uma situação concreta e execute mentalmente seu algoritmo.

Desafio

Crie um algoritmo para calcular a média de duas notas.

Não escreva código.

Descreva apenas os passos necessários para:

  1. receber as duas notas;
  2. calcular a média;
  3. apresentar o resultado.

Síntese

Um algoritmo é uma solução organizada em passos.

Para construir um bom algoritmo, precisamos:

  • compreender o objetivo;
  • organizar os passos;
  • respeitar a ordem;
  • testar a solução.
