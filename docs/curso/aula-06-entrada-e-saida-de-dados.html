Curso de Algoritmos I

Aula 06 — Entrada e saída de dados

Objetivos

Compreender entrada e saída, utilizar LEIA e ESCREVA e construir algoritmos que recebam dados, processem informações e apresentem resultados.

Provocação

Um programa não deve depender apenas de valores escritos dentro do código. Ele precisa conversar com o mundo.

Por isso podemos pensar em:

Entrada → Processamento → Saída

1. Entrada

Entrada é uma informação fornecida ao algoritmo.

Em Sophia usamos LEIA.

INICIO
    TEXTO nome RECEBE ""
    LEIA "Digite o seu nome " nome
    ESCREVA nome
FIM

2. Saída

Saída é uma informação apresentada pelo algoritmo.

ESCREVA "Olá!"
ESCREVA nome

3. Entrada, processamento e saída

PROGRAMA "Dobro"

INICIO
    NUMERO num RECEBE 0
    NUMERO resultado RECEBE 0
    
    LEIA "Digite um número: " num
    
    resultado RECEBE num VEZES 2
    ESCREVA resultado
FIM

Fluxo:

  1. recebe numero;
  2. calcula o dobro;
  3. apresenta resultado.

4. Mais de uma entrada

PROGRAMA "Soma"

INICIO
    NUMERO primeiro RECEBE 0
    NUMERO segundo RECEBE 0
    NUMERO resultado RECEBE 0

    LEIA "Informe o primeiro numero " primeiro
    LEIA "Informe o segundo numero " segundo
    resultado RECEBE primeiro MAIS segundo
    ESCREVA resultado
FIM

A ordem importa: os dados precisam ser recebidos antes de serem utilizados.

5. Especificação antes do código

Para somar dois números:

Problema: somar dois números.

Entrada: dois números.

Processamento: somar os números.

Saída: resultado.

Essa forma de pensar evita começar diretamente pelo código.

6. Testes

Para o algoritmo da soma, teste:

| Primeiro | Segundo | Resultado | |---:|---:|---:| | 5 | 7 | 12 | | 0 | 10 | 10 | | -5 | 3 | -2 |

Testar diferentes valores ajuda a validar o comportamento.

Exercícios

Nível A

  1. O que é entrada?
  2. O que é saída?
  3. Para que serve LEIA?
  4. Para que serve ESCREVA?

Nível B

Identifique entrada, processamento e saída para:

  1. dobro de um número;
  2. soma de dois números;
  3. média de três notas.

Nível C

Crie um algoritmo que leia dois números e apresente soma, diferença e produto.

Nível D

Com primeiro = 10 e segundo = 4, qual será o resultado de primeiro MENOS segundo?

Nível E

Corrija a ordem:


INICIO
    NUMERO num RECEBE 0 
    NUMERO resultado RECEBE 0

    resultado RECEBE num VEZES 2
    LEIA "Informe um numero " num
    ESCREVA resultado
FIM

Desafio

Leia o nome de um aluno e três notas. Armazene e apresente todas as informações.

IA como ferramenta

Peça à IA casos de teste para um algoritmo que recebe dois números e calcula a soma. Depois verifique se os testes realmente cobrem situações diferentes.

Síntese

LEIA recebe dados. ESCREVA apresenta dados. Um algoritmo pode transformar entradas em saídas, e identificar entrada, processamento e saída é uma etapa importante da especificação.
