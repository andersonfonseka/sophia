Aula 10 — Problemas matemáticos

Da situação para o cálculo

Um problema matemático apresentado em texto não mostra diretamente o programa que devemos escrever.

Precisamos transformar a situação em uma solução.

O caminho é:

PROBLEMA
    ↓
ENTRADAS
    ↓
PROCESSAMENTO
    ↓
SAÍDA
    ↓
ALGORITMO
    ↓
PROGRAMA
    ↓
TESTES

Exemplo: média

Problema:

Um aluno recebeu as notas 7 e 9. Qual é a média?

Entradas

Temos:

  • primeira nota;
  • segunda nota.

Processamento

A média é calculada pela soma das notas dividida pela quantidade de notas.

nota1 MAIS nota2 DIVIDIDO POR 2

Saída

A média.

Programa

PROGRAMA "Media"

INICIO
    NUMERO nota1 RECEBE 0
    NUMERO nota2 RECEBE 0
    NUMERO soma RECEBE 0
    NUMERO media RECEBE 0

    nota1 RECEBE 7
    nota2 RECEBE 9
    soma RECEBE nota1 MAIS nota2
    media RECEBE soma DIVIDIDO POR 2
    ESCREVA media
FIM

Atenção à expressão

Observe:

nota1 MAIS nota2 DIVIDIDO POR 2

A precedência das operações precisa ser considerada.

Se a intenção é somar as duas notas antes de dividir por 2, a solução precisa representar essa relação de forma compatível com a sintaxe disponível na Sophia.

Como a Sophia não utiliza parênteses, a construção da expressão deve respeitar os recursos e a precedência definidos pela linguagem.

Esse é um ponto importante:

Nem toda fórmula matemática pode ser simplesmente copiada para qualquer linguagem de programação.

Precisamos aprender a expressar a solução na linguagem que estamos utilizando.

Exemplo: área de um retângulo

Problema:

Calcular a área de um retângulo sabendo sua base e sua altura.

A fórmula é:

base VEZES altura

Programa:

PROGRAMA "AreaRetangulo"

INICIO
    NUMERO base RECEBE 0
    NUMERO altura RECEBE 0
    NUMERO area RECEBE 0

    base RECEBE 8
    altura RECEBE 5
    area RECEBE base VEZES altura
    ESCREVA area
FIM

Resultado:

40

Exemplo: perímetro

O perímetro de um retângulo pode ser calculado somando seus quatro lados.

Para um retângulo com base 8 e altura 5:

8 MAIS 8 MAIS 5 MAIS 5

Programa:

PROGRAMA "Perimetro"

INICIO
    NUMERO base RECEBE 0
    NUMERO altura RECEBE 0
    NUMERO perimetro RECEBE 0

    base RECEBE 8
    altura RECEBE 5
    perimetro RECEBE base MAIS base MAIS altura MAIS altura
    ESCREVA perimetro
FIM

Exemplo: desconto

Problema:

Um produto custa 200 reais e recebe um desconto de 20 reais. Qual é o preço final?

Entradas:

  • preço;
  • desconto.

Processamento:

preco MENOS desconto

Programa:

PROGRAMA "Desconto"

INICIO
    NUMERO preco RECEBE 0
    NUMERO desconto RECEBE 0
    NUMERO final RECEBE 0

    preco RECEBE 200
    desconto RECEBE 20
    final RECEBE preco MENOS desconto
    ESCREVA final
FIM

Exemplo: conversão

Problema:

Uma distância de 5 quilômetros corresponde a quantos metros?

Sabemos que:

1 quilometro = 1000 metros

Portanto:

quilometros VEZES 1000

Programa:

PROGRAMA "QuilometrosParaMetros"

INICIO
    NUMERO quilometros RECEBE 0
    NUMERO metros RECEBE 0

    quilometros RECEBE 5
    metros RECEBE quilometros VEZES 1000
    ESCREVA metros
FIM

O cálculo deve nascer do problema

Não devemos escolher uma operação apenas porque ela existe.

Primeiro compreendemos a situação.

Depois perguntamos:

Qual relação entre os dados produz a resposta?

Essa relação é o processamento.

Uma técnica para resolver problemas

Para qualquer problema matemático simples, escreva:

1. Problema

O que precisa ser descoberto?

2. Entradas

Quais informações são necessárias?

3. Processamento

Qual cálculo transforma as entradas na resposta?

4. Saída

O que será apresentado?

5. Teste

Qual resultado esperamos para um conjunto conhecido de valores?

Atividade

Resolva antes de escrever Sophia:

  1. calcular a área de um quadrado;
  2. calcular o dobro de um número;
  3. calcular o valor de uma compra com três produtos de mesmo preço;
  4. converter horas em minutos;
  5. calcular o consumo de um veículo sabendo distância percorrida e combustível utilizado.

Para cada problema, escreva:

PROBLEMA
ENTRADAS
PROCESSAMENTO
SAÍDA
TESTE

Desafio

Uma pessoa deseja calcular o custo de uma viagem.

Ela sabe:

  • a distância da viagem;
  • o consumo do veículo em quilômetros por litro;
  • o preço do litro do combustível.

Descubra:

  1. quais são as entradas;
  2. qual cálculo determina a quantidade de combustível;
  3. qual cálculo determina o custo;
  4. qual é a saída;
  5. como testar a solução.

Depois transforme sua solução em um programa Sophia.

Síntese

Resolver um problema matemático com programação não significa apenas fazer uma conta.

É necessário:

  • compreender a situação;
  • identificar os dados;
  • descobrir a relação entre eles;
  • construir o processamento;
  • definir a saída;
  • escrever o algoritmo;
  • implementar;
  • testar.

O cálculo é apenas uma parte da solução.
