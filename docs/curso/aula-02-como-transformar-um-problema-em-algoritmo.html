Curso de Algoritmos I

Aula 02 — Como transformar um problema em algoritmo?

O desafio

Na aula anterior, aprendemos que um algoritmo é uma solução organizada em passos.

Mas como saímos de um problema e chegamos a esses passos?

Precisamos aprender a transformar uma situação em uma solução organizada.

Primeiro: compreender o problema

Antes de pensar em comandos, precisamos entender o que está sendo pedido.

Pergunte:

  • Qual é o objetivo?
  • Quais informações eu tenho?
  • O que preciso descobrir?
  • Quais informações precisam ser fornecidas?
  • Existe alguma regra que deve ser respeitada?

Essas perguntas ajudam a transformar uma descrição em algo que podemos trabalhar.

Entrada, processamento e saída

Uma forma simples de organizar um problema é identificar:

ENTRADA → PROCESSAMENTO → SAÍDA

Considere o problema:

Calcular o dobro de um número.

Entrada

Um número.

Processamento

Multiplicar o número por 2.

Saída

O dobro do número.

Agora o problema está mais organizado.

Segundo: decompor

Um problema pode ser dividido em partes menores.

Imagine o problema:

Calcular o preço final de um produto com desconto.

Podemos dividir em:

  1. receber o preço;
  2. receber o percentual de desconto;
  3. calcular o valor do desconto;
  4. calcular o preço final;
  5. apresentar o resultado.

A decomposição torna o problema mais fácil de compreender.

Terceiro: organizar os passos

Depois de identificar as partes, precisamos colocá-las em uma ordem lógica.

Considere:

  1. calcular o desconto;
  2. apresentar o preço final;
  3. receber o preço;
  4. receber o desconto.

Essa sequência não funciona porque tentamos calcular antes de possuir os dados necessários.

Uma ordem melhor é:

  1. receber o preço;
  2. receber o desconto;
  3. calcular o desconto;
  4. calcular o preço final;
  5. apresentar o resultado.

Quarto: verificar se os passos são suficientes

Depois de criar o algoritmo, precisamos perguntar:

Com esses passos consigo resolver o problema?

Se a resposta for não, precisamos voltar e melhorar a solução.

Construir algoritmos não é simplesmente escrever uma sequência uma única vez.

É um processo de análise e melhoria.

Exemplo completo

Problema:

Calcular o dobro de um número.

Compreensão

Precisamos de um número e queremos produzir o seu dobro.

Decomposição

  1. obter o número;
  2. multiplicar por 2;
  3. apresentar o resultado.

Algoritmo

Início

  1. receber um número;
  2. multiplicar o número por 2;
  3. apresentar o resultado.

Fim

Observe que ainda não precisamos de uma linguagem de programação.

A solução já existe.

Do problema ao algoritmo

Podemos resumir o processo:

PROBLEMA

↓

COMPREENDER

↓

IDENTIFICAR DADOS

↓

DECOMPOR

↓

ORGANIZAR PASSOS

↓

TESTAR

↓

ALGORITMO

Essa sequência será usada durante todo o curso.

Testando uma solução

Imagine que o número recebido seja 5.

Executamos:

  1. receber 5;
  2. calcular 5 vezes 2;
  3. apresentar 10.

O resultado esperado foi produzido.

Agora podemos considerar a solução válida para esse caso.

Testar casos diferentes

Um único teste não é suficiente para todos os problemas.

No exemplo do dobro, podemos testar:

  • 5 → 10;
  • 10 → 20;
  • 0 → 0;
  • 3 → 6.

Testar diferentes situações ajuda a encontrar problemas na solução.

Quando a solução parece difícil

Quando um problema parece grande demais, não tente resolver tudo de uma vez.

Pergunte:

Qual é a menor parte que consigo resolver primeiro?

Depois:

Qual é a próxima parte?

Esse processo de decomposição será uma das principais ferramentas do pensamento algorítmico.

Atividade 1 — Entrada, processamento e saída

Para cada problema, identifique a entrada, o processamento e a saída:

  1. calcular a área de um retângulo;
  2. calcular a média de duas notas;
  3. converter horas em minutos.

Atividade 2 — Organize os passos

Organize os passos abaixo para calcular a média de duas notas:

  • apresentar a média;
  • receber a primeira nota;
  • calcular a média;
  • receber a segunda nota.

Atividade 3 — Encontre o problema

Um algoritmo apresenta o resultado antes de receber os dados.

Explique por que existe um problema nessa solução.

Desafio

Crie um algoritmo para calcular o preço final de um produto depois de um desconto.

Defina:

  • quais são as entradas;
  • quais são os processamentos;
  • qual é a saída;
  • quais são os passos na ordem correta.

Não escreva código.

Síntese

Transformar um problema em algoritmo envolve:

  1. compreender;
  2. identificar os dados;
  3. decompor;
  4. organizar;
  5. testar;
  6. validar.
