Comece agora

Você pode começar a programar com Sophia de duas formas: usando a Sophia IDE ou utilizando a CLI e o REPL.

1. Requisitos

Para executar a Sophia 1.0.0, você precisa de uma instalação do Java 17+ compatível com a versão utilizada na distribuição.

2. Escolha como começar

Sophia IDE

A forma mais simples de começar. Escreva, organize, salve e execute seus programas em um ambiente visual.

Conhecer a Sophia IDE

CLI e REPL

Para quem prefere trabalhar pelo terminal ou experimentar a linguagem de forma interativa.

Ver o REPL

3. Baixe a Sophia

A Sophia IDE possui uma distribuição própria para facilitar o primeiro contato com a linguagem.

Download Sophia IDE 0.1.0 Download Sophia CLI 1.0.0

4. Execute a Sophia

Depois de baixar a Sophia, abra um terminal na pasta onde está o arquivo sophia-cli-1.0.0.jar e execute: 

java -jar sophia-cli-1.0.0.jar

Para iniciar o ambiente interativo da Sophia (REPL), execute: 

java -jar sophia-cli-1.0.0.jar repl

A partir daí você pode escrever comandos Sophia diretamente no REPL.

4.1 Escreva seu primeiro programa

programa "Primeiro Programa"

inicio

    numero idade recebe 20

    escreva idade

fim

Na Sophia, as variáveis são declaradas e inicializadas explicitamente. A linguagem utiliza palavras em português para expressar a lógica do programa.

5. Execute

Na Sophia IDE, clique em Executar. O resultado aparecerá na área de saída da própria IDE. 

20

6. Experimente o REPL

O REPL permite experimentar comandos Sophia diretamente no terminal, sem precisar criar um programa completo. 

sophia> numero idade recebe 51
sophia> se idade maior ou igual a 18
... escreva "Maior"
... senao
... escreva "Menor"
... fim
Maior
sophia>
