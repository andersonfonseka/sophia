Comece agora

1. Requisitos

Para executar a Sophia 1.0.0 você precisa apenas de uma instalação do Java 17+ compatível com a versão utilizada na distribuição.

2. Baixe a Sophia

Baixe o arquivo executável na Release 1.0.0:

Download Sophia 1.0.0

3. Execute o REPL

java -jar sophia-cli-1.0.0.jar repl

4. Escreva seu primeiro programa

numero idade recebe 20

escreva idade

5. Experimente

sophia> numero idade recebe 20
sophia> escreva idade

20
