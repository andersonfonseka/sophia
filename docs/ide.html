Sophia IDE

A Sophia IDE é o ambiente de desenvolvimento da linguagem Sophia, criado para tornar a programação simples, visual e acessível.

Download Sophia IDE 0.1.0

A IDE permite escrever, organizar, salvar e executar programas Sophia sem depender do terminal. A proposta é manter a simplicidade da linguagem, oferecendo uma experiência de uso mais confortável.

Imagem da Sophia IDE

Um ambiente simples para programar

A interface é organizada em três áreas principais: a árvore do projeto, o editor de código e a área de saída. Dessa forma, o programador consegue visualizar o projeto, escrever o programa e acompanhar sua execução no mesmo ambiente.

  • Árvore de projetos e programas
  • Editor de código com numeração de linhas
  • Syntax highlighting da linguagem Sophia
  • Realce da gramática durante a edição
  • Área de saída para os resultados da execução
  • Mensagens de execução e erros

Programas e projetos

A IDE diferencia a criação de um novo programa da criação de um projeto. Um programa Sophia pode ser criado ou aberto diretamente, enquanto um projeto permite organizar vários programas em uma estrutura de arquivos.

  • Novo Programa — cria um novo arquivo Sophia.
  • Abrir Programa — abre um programa existente.
  • Criar Projeto — cria uma nova estrutura de projeto.
  • Abrir Projeto — abre uma pasta como projeto Sophia.
  • Salvar — salva o programa atualmente editado.
  • Executar — executa o programa Sophia.

Editor com destaque da linguagem

Enquanto o programa é escrito, a IDE reconhece os elementos da linguagem e aplica destaque visual à sua gramática. Estruturas, tipos, comandos, identificadores e literais podem ser diferenciados visualmente.

O destaque é atualizado durante a digitação, permitindo que o editor permaneça útil mesmo enquanto o programa ainda está sendo construído.

Execução e entrada de dados

O programa pode ser executado diretamente pela IDE e seu resultado aparece na área de saída.

Programas que utilizam o comando leia podem solicitar a entrada de dados por meio de uma janela de entrada, mantendo a execução dentro da experiência da Sophia IDE.

Uma IDE para aprender programação

A Sophia IDE não pretende competir com ambientes profissionais de desenvolvimento. Seu objetivo é oferecer um espaço pequeno, direto e didático para aprender programação e experimentar os conceitos da linguagem Sophia.

A combinação de uma linguagem de sintaxe expressiva com uma IDE visual reduz a distância entre escrever um programa e observar imediatamente o que ele faz.

Estado atual

A Sophia IDE já possui editor, árvore de projetos, abertura e salvamento de programas, execução, área de saída, destaque de sintaxe e suporte à organização de projetos. A ferramenta continua evoluindo junto com a linguagem Sophia.
