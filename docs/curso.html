Por que aprender algoritmos na era da IA?

A inteligência artificial já consegue produzir código. Isso não elimina a necessidade de aprender algoritmos.

Para utilizar código produzido por uma IA de forma responsável, ainda é necessário compreender o problema, definir o que deve ser resolvido, avaliar a solução e validar o resultado.

Este curso começa antes do código. Ele começa pelo problema e pelo raciocínio necessário para transformá-lo em uma solução.

O que você vai aprender

Pensamento algorítmico

Aprender a decompor problemas e organizar soluções passo a passo.

Programação com Sophia

Expressar algoritmos utilizando uma linguagem de programação em português.

Estruturas fundamentais

Trabalhar com dados, operações, decisões, repetição, funções e listas.

Validação

Testar algoritmos, acompanhar sua execução, identificar erros e verificar resultados.

Como estudar

Cada aula parte de um problema, apresenta o conceito, mostra sua expressão em Sophia e propõe atividades para construir e validar a solução.

1. Compreender

Entenda o problema antes de pensar no código.

2. Construir

Organize os passos necessários para resolver o problema.

3. Expressar

Transforme a solução em um programa Sophia.

4. Validar

Execute, teste e verifique se o algoritmo realmente funciona.
